Patakaran sa privacy
Huling na-update: 10 Oktubre 2026 · Android app na Ricorda
Package: com.fabio.ricorda

Nananatili sa iyong device ang mga paalala mo.
Gumagana ang Ricorda nang walang account at hindi nito ipinapadala sa developer ang mga paalala, tala o data ng paggamit. Walang mga ad, analytics o tracking tool ang app.

2. Data na ginagamit ng app
Sa pribadong storage ng app iniimbak ng Ricorda ang data na inilalagay mo: pamagat at tala ng paalala, petsa, oras, pag-uulit at iba pang opsyon. Iniimbak din ang mga pinili mong wika, hitsura, font, tunog, lakas ng tunog, pag-vibrate, notification at santo ng araw kapag available. Gumagamit ng mga lokal na identifier para makilala ang mga paalala at pamahalaan ang mga abiso.
Ginagamit ang data para ipakita at hanapin ang iyong mga gawain, mag-iskedyul ng mga notification at alarm, magpakita ng mga widget at tandaan ang iyong mga pagpili. Ang kalendaryo at mga santo ay gumagamit ng data na kasama sa app. Hindi binabasa ng Ricorda ang mga contact o kalendaryo ng system at hindi ito kumukuha ng lokasyon, mga larawan, audio recording o advertising identifier.

3. Mga link at pagbabahagi
Walang pahintulot sa pag-access sa Internet ang app at hindi ito awtomatikong nagpapadala ng data sa mga server ng developer o sa mga serbisyo ng advertising at analytics. Walang account o online na pag-sync.
Kapag binuksan ang link sa patakarang ito, browser ng device ang hahawak dito. Kung magpapadala ka ng email, gagamitin ang pinili mong email app. May sariling mga patakaran ang mga app at provider na ito.

4. Mga notification, alarm at pahintulot ng Android
Ginagamit ng Ricorda ang mga pahintulot ng Android para magpakita ng notification, mag-iskedyul ng eksaktong alarm, magpakita ng screen ng alarm kapag pinapayagan, tumunog at mag-vibrate. Maaari nitong panatilihing aktibo ang device pansamantala habang may abiso at muling iiskedyul ang mga abiso matapos mag-restart.
Maaari mong pamahalaan ang mga pahintulot sa mga setting ng Android; ang pag-off ay maaaring makalimit sa mga abiso. Maaaring lumitaw ang mga pamagat at tala sa mga notification, screen ng alarm at widget. Nakadepende rin sa mga setting ng telepono ang nakikita sa lock screen: piliin ang angkop sa pagiging pribado ng iyong mga paalala.

5. Pag-export at pag-import ng backup
Kapag hiniling mo lamang, nag-e-export ang Ricorda ng JSON file sa lokasyong pinili mo sa file picker ng Android. Kasama sa backup ang mga paalala, pati nasa basurahan, at mga opsyon nito. Kasama rin ang impormasyon ng backup, gaya ng petsa at oras ng paggawa, brand at modelo ng device at random na identifier ng installation para makilala ang pinagmulan. Maaaring may mga reference sa tunog, pero hindi kinokopya ang mga audio file sa backup.
Hindi ine-encrypt ng app ang backup file. Sinumang nakakabasa nito ay makakakuha ng nilalamang data. Kung cloud service ang pipiliin mo, ang provider nito ang hahawak sa file ayon sa sariling tuntunin at patakaran sa privacy; hindi ito ipinapadala ng Ricorda sa developer. Sa pag-import, binabasa ang file na pinili mo para ibalik o pagsamahin ang mga paalala.

6. Pag-iingat, pagbura at seguridad
Nananatili ang data sa pribadong storage ng app habang ginagamit mo ito o hanggang burahin mo ito sa Android. Ang paglipat ng paalala sa basurahan ay nagpapanatili nito para maibalik; hindi iyon permanenteng pagbura.
Para burahin ang lahat ng lokal na data ng Ricorda, gamitin ang pagbura ng data ng app sa mga setting ng Android o i-uninstall ang app. Nananatili ang mga na-export na backup sa piniling lokasyon at kailangang burahin nang hiwalay, pati sa mga cloud service.
Ginagamit ng Ricorda ang paghihiwalay ng pribadong storage na ibinibigay ng Android at pinapatay ang awtomatikong backup ng app. Hindi ito nagdaragdag ng sariling encryption sa data o na-export na mga file. Nakadepende rin ang proteksyon sa lock screen, seguridad ng device at paraan ng pag-iingat ng backup. Hindi maa-access, maibabalik o mabubura ng developer nang malayuan ang iyong mga lokal na paalala.

7. Mga kahilingan sa suporta at mga karapatan
Kung susulat ka sa nakasaad na contact, kusang ibinabahagi mo ang iyong email address at nilalaman ng mensahe. Ginagamit ang data para sagutin at pangasiwaan ang kahilingan, batay sa pangangailangang ibigay ang hiniling mong suporta at, kung naaangkop, tuparin ang mga legal na obligasyon. Itinatago ito sa panahong kailangan upang pangasiwaan ang kahilingan at mga naaangkop na obligasyon. Iwasang magpadala ng mga paalala o backup na may impormasyong hindi kailangan para sa suporta.
Para sa data na maaaring natanggap ng developer, maaari kang humiling ng access, pagwawasto, pagbura, paghihigpit, pagtutol at portability sa mga kasong pinapahintulutan ng naaangkop na batas, sa pamamagitan ng fabiocorby@gmail.com. Maaari ka ring lumapit sa karampatang awtoridad sa pangangasiwa, sa Italya ay ang Garante per la protezione dei dati personali. Para sa data na nasa telepono lamang, gamitin ang mga tungkulin ng app at Android na inilarawan sa itaas.
