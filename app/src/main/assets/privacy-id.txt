Ricorda

Kebijakan privasi
Diperbarui: 10 Oktober 2026 · Aplikasi Android Ricorda
Paket: com.fabio.ricorda

Pengingat Anda tetap berada di perangkat Anda.
Ricorda berfungsi tanpa akun dan tidak mengirim pengingat, catatan, atau data penggunaan kepada pengembang. Aplikasi tidak memuat iklan, alat analisis, atau pelacakan.

1. Pengembang dan kontak
Ricorda dikembangkan oleh Fabio Avitabile. Untuk pertanyaan privasi, bantuan, dan keperluan lain, hubungi fabiocorby@gmail.com. Fabio Avitabile bertanggung jawab atas pemrosesan yang dijelaskan dalam kebijakan ini yang dilakukan oleh pengembang, seperti menangani permintaan bantuan.

2. Data yang digunakan aplikasi
Ricorda menyimpan data yang Anda masukkan di penyimpanan pribadi aplikasi: judul dan catatan pengingat, tanggal, waktu, pengulangan, serta opsi pengingat lainnya. Aplikasi juga menyimpan pilihan bahasa, tampilan, jenis huruf, suara, volume, getaran, notifikasi, dan santo hari ini jika tersedia. Pengenal lokal digunakan untuk membedakan pengingat dan mengelola pemberitahuan.
Data ini digunakan untuk menampilkan dan mencari jadwal, menjadwalkan notifikasi dan alarm, menampilkan widget, serta mengingat pilihan Anda. Kalender dan fitur santo menggunakan data yang disertakan dalam aplikasi. Ricorda tidak membaca kontak atau kalender sistem dan tidak mengambil lokasi, foto, rekaman audio, atau pengenal iklan.

3. Tautan dan berbagi
Aplikasi tidak memiliki izin akses Internet dan tidak otomatis mengirim data ke server pengembang atau layanan iklan dan analisis. Tidak tersedia akun atau sinkronisasi daring.
Saat membuka tautan kebijakan ini, peramban perangkat menanganinya. Jika mengirim email, aplikasi email yang Anda pilih akan menanganinya. Aplikasi tersebut dan penyedianya mengikuti kebijakan privasi masing-masing.

4. Notifikasi, alarm, dan izin Android
Ricorda menggunakan izin Android untuk menampilkan notifikasi, menjadwalkan alarm tepat waktu, menampilkan layar alarm bila diizinkan, memutar suara, dan bergetar. Aplikasi dapat menjaga perangkat tetap aktif sementara selama pemberitahuan dan menjadwalkan ulang pemberitahuan setelah perangkat dimulai ulang.
Anda dapat mengelola izin di pengaturan Android; menonaktifkannya dapat membatasi pemberitahuan. Judul dan catatan dapat muncul di notifikasi, layar alarm, dan widget. Tampilan di layar terkunci juga bergantung pada pengaturan ponsel: pilih pengaturan yang sesuai dengan kerahasiaan pengingat Anda.

5. Ekspor dan impor cadangan
Hanya atas permintaan Anda, Ricorda mengekspor file JSON ke lokasi yang dipilih melalui pemilih file Android. Cadangan berisi pengingat, termasuk yang berada di sampah, beserta opsinya. Cadangan juga berisi informasi seperti tanggal dan waktu pembuatan, merek dan model perangkat, serta pengenal instalasi acak untuk mengenali asal cadangan. Referensi suara dapat disertakan, tetapi file audio tidak disalin ke cadangan.
File cadangan tidak dienkripsi oleh aplikasi. Siapa pun yang dapat membacanya dapat mengakses isinya. Jika memilih layanan cloud, penyedia tersebut menangani file sesuai ketentuan dan kebijakan privasinya; Ricorda tidak mengirimnya kepada pengembang. Impor membaca file pilihan Anda untuk memulihkan atau menggabungkan pengingat.

6. Penyimpanan, penghapusan, dan keamanan
Data tetap berada di penyimpanan pribadi aplikasi selama Anda menggunakannya atau sampai dihapus melalui Android. Memindahkan pengingat ke sampah mempertahankannya agar dapat dipulihkan; ini bukan penghapusan permanen.
Untuk menghapus seluruh data lokal Ricorda, gunakan fitur hapus data aplikasi di pengaturan Android atau hapus instalasi aplikasi. Cadangan yang diekspor tetap berada di lokasi pilihan Anda dan harus dihapus secara terpisah, termasuk dari layanan cloud.
Ricorda menggunakan isolasi penyimpanan pribadi yang disediakan Android dan menonaktifkan pencadangan otomatis aplikasi. Aplikasi tidak menambahkan enkripsi sendiri pada data atau file ekspor. Perlindungan juga bergantung pada kunci layar, keamanan perangkat, dan cara Anda menyimpan cadangan. Pengembang tidak dapat mengakses pengingat lokal Anda atau memulihkan maupun menghapusnya dari jarak jauh.

7. Permintaan bantuan dan hak Anda
Jika menghubungi alamat di atas, Anda secara sukarela membagikan alamat email dan isi pesan. Data digunakan untuk menjawab dan menangani permintaan Anda, berdasarkan kebutuhan memberikan bantuan yang diminta dan, jika berlaku, memenuhi kewajiban hukum. Data disimpan selama diperlukan untuk menangani permintaan serta kewajiban terkait. Hindari mengirim pengingat atau cadangan yang berisi informasi tidak diperlukan untuk bantuan.
Untuk data yang mungkin diterima pengembang, Anda dapat meminta akses, perbaikan, penghapusan, pembatasan, keberatan, dan portabilitas sejauh diatur hukum yang berlaku, melalui fabiocorby@gmail.com. Anda juga dapat menghubungi otoritas pengawas yang berwenang, di Italia yaitu Garante per la protezione dei dati personali. Untuk data yang hanya berada di ponsel, gunakan fungsi aplikasi dan Android yang dijelaskan di atas.

8. Halaman web ini
Halaman ini tidak memuat iklan, formulir pengumpulan data, atau alat analisis yang ditambahkan pengembang. Halaman dihosting melalui Sites. Penyedia hosting dapat memproses data teknis kunjungan, seperti alamat IP, informasi peramban, dan log akses, untuk menyediakan serta melindungi layanan sesuai kebijakan privasinya. Mengunjungi halaman tidak mengirim pengingat yang tersimpan di aplikasi.
